How to use External GPU

  1. Open one of the free services above and create a new notebook.
  2. Upload the app.py and logic_ai_upscaler.py to the notebook.
  3. Install requirements: !pip install flask flask-cors opencv-python torch torchvision
  4. Run the app with LocalTunnel or Ngrok to get a public URL.
  5. Paste that public URL below and click "Save & Connect".
  6. In the main UI, set Processing Mode to External Cloud GPU.
