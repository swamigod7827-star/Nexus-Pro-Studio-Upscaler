# Nexus Pro Studio - AI Upscaler

Nexus Pro Studio is an advanced AI upscaling application that leverages powerful deep learning models like RealESRGAN and GFPGAN to enhance, restore, and upscale images.

## Features
- Smart Hardware Auto-Detection (CPU/Local GPU/Cloud GPU).
- Support for multiple AI Models (RealESRGAN, GFPGAN, CodeFormer, etc).
- Direct integration with free Cloud GPUs (Colab, Kaggle, Lightning AI).
- Stunning, professional-grade user interface.

## How to use on Cloud GPU
To run this project instantly on a free Cloud GPU, navigate to the `Cloud_Workspaces` folder and open the setup notebook for your preferred platform. Upload the notebook to the cloud platform and run the cells.
